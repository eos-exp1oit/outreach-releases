# Outreach for Windows

Outreach 프로그램 업데이트를 배포하는 저장소입니다.

[최신 버전 다운로드](https://github.com/eos-exp1oit/outreach-releases/releases/latest)

기존 사용자는 앱을 종료한 뒤 `Outreach-<version>-Update.zip` 안의 파일을 기존 `Outreach.exe` 폴더에 덮어쓰세요. `Outreach-data`는 보존하세요. 1.5.1 이상에서는 설정에서 다음 버전을 다운로드하고 재시작해 적용할 수 있습니다.

이 저장소와 공개 업데이트에는 Gmail 연결, API 키, 회사 자료, 개인 작업 내역이 포함되지 않습니다. 신규 직원은 관리자에게 별도로 제공되는 직원용 파일과 회사 초대 코드를 받으세요.

각 버전의 `latest.json`은 앱이 검증하는 서명된 업데이트 정보입니다. ZIP을 변경하거나 이름을 바꿔 재게시하지 마세요.
